# Diabetes Prediction Model

A Machine Learning-based Diabetes Prediction System that predicts whether a person is likely to have diabetes based on health-related parameters.

## Project Overview

This project uses Machine Learning to analyze patient health data and predict the possibility of diabetes. The model is trained on a diabetes dataset and evaluated using accuracy on training and test data.

## Features

- Diabetes prediction using Machine Learning
- Data preprocessing and standardization
- Training and test data evaluation
- Prediction based on patient health parameters
- Simple and easy-to-understand implementation

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Machine Learning

## Project Demo

A demonstration video of the Diabetes Prediction Model is included in this repository.

**Demo Video:** `Diabetes Model.mp4`

## How It Works

1. Patient health parameters are provided as input.
2. The input data is converted into a NumPy array.
3. The data is standardized using the trained scaler.
4. The trained Machine Learning classifier makes a prediction.
5. The system displays whether the person is likely to be diabetic or non-diabetic.

## Model Evaluation

The model calculates accuracy on both training and test data to evaluate its performance.
